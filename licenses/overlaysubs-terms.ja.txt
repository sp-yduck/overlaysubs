OverlaySubs 利用規約（第3版）

第1条（本規約）
OverlaySubs（以下「本アプリ」）を利用するには、本規約に同意する必要があります。同意しない場合は本アプリを利用できません。

第2条（本アプリのライセンス）
本アプリのソースコードは MIT ライセンスで提供されます。本アプリは現状のまま提供され、明示・黙示を問わず一切の保証はありません。

第3条（翻訳モデル PLaMo）
1. 本アプリは、株式会社Preferred Networks（以下「PFN」）の翻訳モデル PLaMo 3 Translate をダウンロードして使います。
2. PLaMo 3 Translate の利用条件は、PFN が定める PLaMo 3 のライセンスに従います。ライセンスは次のページで確認できます。
   https://plamo.preferredai.jp/info/plamo-community-license-ja
3. ユーザーは、本アプリで PLaMo 3 Translate を利用する場合、前項のライセンスを確認し、これに従うものとします。

第4条（その他のモデル）
音声認識の Whisper（OpenAI、MIT ライセンス）と音声区間検出の Silero VAD（MIT ライセンス）は、それぞれのライセンスに従います。

第5条（字幕・翻訳結果）
1. 字幕は機械による文字起こしと翻訳であり、誤りを含むことがあります。正確さが求められる用途では、ユーザーの責任で確認してください。
2. 字幕を公開・配布する場合は、元のコンテンツの著作権や配信元の規約を守ってください。

第6条（プライバシー）
音声、文字起こし、翻訳は端末内だけで処理し、外部に送信しません。テレメトリはありません。通信は、モデルのダウンロード（Hugging Face）と、起動時に新しいリリースがあるかを確認するための GitHub API への匿名のリクエスト 1 回だけです（アカウント・トークン・個人データは送信しません。失敗しても何も起きません）。

第7条（免責）
本アプリの利用によって生じた損害について、開発者は責任を負いません。

第8条（改定）
本規約を改定した場合は、次回起動時に改めて同意をお願いします。
